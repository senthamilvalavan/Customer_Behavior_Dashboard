# Customer Shopping Behavior Analysis 🛒📊

## Project Overview
This project is an end-to-end data analysis pipeline designed to extract actionable insights from customer purchasing data. The workflow encompasses data ingestion, database integration, exploratory data analysis (EDA), and interactive visualization. 

## Tech Stack & Tools
* **Data Manipulation:** Python (Pandas)
* **Database Management:** PostgreSQL, SQLAlchemy (psycopg2)
* **Querying & Analysis:** SQL
* **Data Visualization:** Power BI

## Repository Structure
* \`customer_shopping_behavior.csv\`: The raw dataset containing customer demographics, purchase amounts, item categories, ratings, and subscription statuses.
* \`customer_behavior.ipynb\`: Jupyter Notebook responsible for loading the raw CSV data and migrating it into a local PostgreSQL database using an SQLAlchemy engine.
* \`customer_behavior_sql.sql\`: Contains advanced SQL queries utilized to uncover key business metrics from the database.
* \`customer_behavior_bi.pbix\`: The Power BI dashboard file containing comprehensive visual reports and data models.

## Key Insights & Analytics
The SQL analysis specifically targets the following business questions:
1. **Demographic Revenue:** Comparing total revenue generated by Male vs. Female customers.
2. **Discount Effectiveness:** Identifying high-value customers who utilized discounts but still spent above the average purchase threshold.
3. **Product Performance:** Ranking the Top 5 products based on the highest average customer review ratings.

## Getting Started

### Prerequisites
* Python 3.8+ (with Pandas and SQLAlchemy installed)
* PostgreSQL database system
* Microsoft Power BI Desktop

### Setup Instructions
1. **Database Configuration:**
   * Open pgAdmin and create a new database named \`customer_behavior\`.
   * Ensure your local PostgreSQL credentials match the engine connection string in the notebook (default user: \`postgres\`, password: \`data\`, port: \`5432\`).
2. **Data Pipeline:**
   * Run the \`customer_behavior.ipynb\` notebook to load the \`customer_shopping_behavior.csv\` data and automatically create/populate the \`customer\` table in your PostgreSQL database.
3. **Data Analysis:**
   * Execute the queries in \`customer_behavior_sql.sql\` within your SQL environment to view the raw business metrics.
4. **Visualization:**
   * Open \`customer_behavior_bi.pbix\` in Power BI Desktop to interact with the visualizations. Make sure to refresh the data source connections if prompted.
